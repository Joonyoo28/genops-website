# GenOps Website

Official GenOps website repository.

This site includes:
- Career services and live Stripe payment links
- Resume intake form
- Free Talent Network resume submission
- Employer recruiting inquiry form
- GenOps LinkedIn and contact information

## Deploying with Vercel
Import this GitHub repository into Vercel and deploy from the `main` branch. Once connected, future commits to `main` can automatically trigger a new Vercel deployment.

## Form activation
The forms use FormSubmit and send submissions to Joonyoo28@gmail.com. After the first live submission for each form, approve the FormSubmit activation email before relying on the forms publicly.
